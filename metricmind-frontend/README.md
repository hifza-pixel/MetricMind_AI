# 🚀 MetricMind AI

An AI-powered Business Intelligence Dashboard built using Next.js, React, Tailwind CSS, TypeScript, and Recharts.


## ✨ Features

 🔐 Authentication System
 📊 Executive Dashboard
 📈 KPI Cards
 📉 Revenue Analytics
 🌍 Sales Region Analysis
 🤖 AI Forecast Dashboard
 💡 AI Recommendations
 📈 Sales Prediction
 📄 AI Report Center
 👤 User Profile
 ⚙️ Settings
 📋 Reports
 🌙 Dark Mode
 📱 Responsive Design
 ⚠️ Error Handling
 🔍 Search UI
